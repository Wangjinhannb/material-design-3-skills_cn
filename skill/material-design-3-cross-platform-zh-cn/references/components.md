# 组件

Classic baseline 核心目录：buttons、floating-action-button、icon-buttons、segmented-buttons、badges、progress-indicators、snackbars、tooltips、bottom-sheets、cards、carousel、dialogs、divider、lists、side-sheets、bottom-app-bar、top-app-bar、navigation-bar、navigation-drawer、navigation-rail、search、tabs、checkbox、chips、date-pickers、menus、radio-button、sliders、switch、time-pickers、text-fields。

Expressive-only 的 button groups、split button、FAB menu、loading indicator、toolbars 等扩展不属于本 baseline；仅在用户明确切换 baseline 时使用。
