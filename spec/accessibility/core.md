# 无障碍

来源类别：`official-md3` + 各平台官方 accessibility API + Web WCAG/ARIA。

Accessibility 是组件完成定义的一部分。

每个组件至少审查：

- 可访问名称、角色、状态和值；
- 键盘/开关控制的可操作性；
- 可见 focus；
- 文本和 UI 缩放；
- 颜色对比与非颜色提示；
- 错误信息；
- 交互目标；
- reduced motion；
- high contrast；
- screen reader traversal；
- 动态内容通知。

Web 自定义复杂 widget 应 参考 WAI-ARIA APG 的语义与键盘约定，并结合 WCAG 与真实浏览器/AT 测试。APG 示例仅作为交互参考。
