# Design Tokens

## 来源

- `color-light.tokens.json` / `color-dark.tokens.json`：DTCG 2025.10 颜色结构。
- `typography.tokens.json`、`shape.tokens.json`、`elevation.tokens.json`、`state.tokens.json`、`motion.tokens.json`：仓库格式 `repo-md3-token-v1`。

颜色 token 当前采用 DTCG 2025.10 结构。其他 token 暂未声明完整 DTCG composite/resolver 兼容。

参考紫色主题用于生成器和示例测试。产品可替换 role value，role 语义保持不变。
